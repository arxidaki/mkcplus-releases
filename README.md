# MKC+

Use one mouse and keyboard across your Windows PCs and Macs on your local network, and copy & paste between them. Free beta, unlimited devices.

Download it for Windows, Windows ARM or macOS from [mkcplus.com](https://mkcplus.com).

- Control any device from any device
- Arrange devices to match your desk
- Unlimited devices
- Copy & paste text, media, files, complex data
- One-click pairing
- Automatic reconnection, any kind of local network

This repository holds the signed installers and update manifests, and each [release](https://github.com/arxidaki/mkcplus-releases/releases) says what it changed. The source lives in a private repository.
